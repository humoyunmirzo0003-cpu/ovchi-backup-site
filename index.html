OVCHI Backup

OVCHI Backup is a private, owner-operated encrypted backup utility for the OVCHI Telegram AI assistant.

Its intended purpose is to save encrypted backups of assistant configuration, memories, reminders, and voice settings to the operator's authorized Google Drive account.

About this integration

When configured by the owner, OAuth access allows the backup tool to upload and manage backup files. Archives are encrypted before uploading; the private recovery key is kept separately by the owner.

This public website does not collect passwords, tokens or files. Automatic cloud upload must be configured separately.

Read the Privacy Policy or see the project page. Do not post private credentials in public issues.

Independent personal project; not affiliated with Google, OpenAI, or Telegram.
