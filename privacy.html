Privacy Policy

Updated October 28, 2026.

OVCHI Backup is a private, owner-operated tool intended to back up the operator's OVCHI assistant data into an authorized Google Drive account.

Data processed

When the operator enables Google Drive backup, the tool may process OAuth authorization tokens, file metadata, and files selected for encrypted backup, such as assistant configuration, reminders, stored memories, and voice settings.

Use of Google data

Google Drive access is used to upload, list and manage backup files for the operator. Google user data is not sold or used for advertising. This website itself does not collect Google credentials or accept file uploads.

Security and sharing

Backup archives are intended to be encrypted before upload. Decryption keys remain under the operator's control and separate from Drive. Private API credentials must not be committed to the public repository. Google Drive stores files under the operator's authorized account, subject to Google's policies.

Retention and control

The operator can remove stored backup files from their Drive account and revoke app access in Google Account settings. Revocation does not automatically remove files previously uploaded.

Contact

For project questions, see the GitHub repository. Do not post secrets or personal backups in public messages.

The integration is intended to use information received from Google APIs only for the described backup purpose, consistent with the Google API Services User Data Policy, including applicable Limited Use requirements.
